プライバシーポリシー

制定日: 2026年10月23日

本ポリシーは、個人用ツール「taka-video-studio」（以下「本アプリ」）における情報の取り扱いを定めるものです。

1. 本アプリの目的

本アプリは、運営者が所有する YouTube チャンネルに動画を投稿し、そのチャンネルの再生データを確認するためだけに使用します。運営者以外の第三者には提供していません。

2. 取得する情報

本アプリは YouTube API サービスを利用し、運営者が許可した範囲で次の情報にアクセスします。

  • 運営者のチャンネルの基本情報（チャンネルID、チャンネル名）
  • 運営者のチャンネルへの動画・サムネイル・説明文のアップロード
  • 運営者のチャンネルの再生回数、視聴維持率などの統計データ

3. 情報の利用と保存

取得した情報は、動画の投稿と内容改善のための分析にのみ利用します。認証情報は暗号化された保存領域に保管し、統計データは運営者のみが管理する場所に保存します。

4. 第三者への提供

取得した情報を販売、共有、第三者へ提供することはありません。

5. Google API の利用について

本アプリは YouTube API サービスを使用しています。本アプリの利用により、YouTube 利用規約に同意したものとみなされます。Google による情報の取り扱いについては Google プライバシーポリシーをご覧ください。本アプリによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

6. アクセス権の取り消し

本アプリへのアクセス許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消した場合、保存されている認証情報は30日以内に削除します。

Privacy Policy (English)

Effective date: October 23, 2026

taka-video-studio is a personal tool used only to upload videos to, and read analytics for, YouTube channels owned by its operator. It accesses basic channel information, uploads videos, thumbnails and descriptions, and reads channel statistics through the YouTube API Services. This data is used only for publishing and improving the operator's own videos, is stored in storage controlled only by the operator, and is never sold or shared with third parties.

Access can be revoked at any time at Google Account permissions; stored credentials are deleted within 30 days of revocation.
